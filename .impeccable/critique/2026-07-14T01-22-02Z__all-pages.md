## Anti-Patterns Verdict

**LLM assessment**: AI-generated tells present. Active items use thick side borders. Card stats use top-accent stripes. Uppercase tracked eyebrows repeat across sections. Layout density lacks variation.

**Deterministic scan**: Layout detector flags side-tab borders in `D:\jobtrackr\components\layout\Sidebar.tsx` (lines 47, 165).

## Overall Impression
Solid foundation. Nice animations, layout clean. Side-tab accents, top stripes, repeated eyebrows make it look templated. Efficiency for power users low.

## What's Working
- **Prep panel**: Smart tag integration provides context-appropriate interview prep next to notes.
- **Main empty state**: Home/All Jobs empty states have clear illustration, clear message, direct CTA.

## Priority Issues
- **[P1] Banned side-tab borders**: Active nav items in `Sidebar.tsx` use `border-l-4`.
  - *Why it matters*: SaaS/AI generation template tell. Hurts brand polish.
  - *Fix*: Remove `border-l-4`. Accent with solid fill, text color change, or subtle dot.
  - *Suggested command*: `/impeccable quieter`
- **[P1] Banned card top-stripe borders**: `StatsBar.tsx` and `JobCard.tsx` use absolute top-border accent heights (`h-1`).
  - *Why it matters*: Visual noise, lazy card design pattern.
  - *Fix*: Use background tints or standard full borders instead of top-stripe accents.
  - *Suggested command*: `/impeccable quieter`
- **[P2] Inconsistent empty states**: Kanban columns lack CTA or icons. Only display simple text.
  - *Why it matters*: First-timer (Jordan) confusion. No clear next step.
  - *Fix*: Match column empty state to main empty state standard (line icon, title, copy, CTA).
  - *Suggested command*: `/impeccable onboard`
- **[P2] Section eyebrows as scaffolding**: Breadcrumbs, dashboard stats labels, recently added list header use uppercase tracked text.
  - *Why it matters*: Saturated AI scaffold. Creates visual clutter.
  - *Fix*: Standard title/sentence case with standard tracking.
  - *Suggested command*: `/impeccable typeset`
- **[P2] No bulk actions or shortcuts**: Users must drag every single card.
  - *Why it matters*: Power user (Alex) fatigue. High clicks count.
  - *Fix*: Add check boxes to list view for bulk status updates or deletions.
  - *Suggested command*: `/impeccable adapt`

## Persona Red Flags
- **Alex (Power User)**: No keyboard shortcuts. Dragging cards only way to move stages. Cannot bulk delete or archive stale applications.
- **Jordan (First-Timer)**: Kanban columns show static text when empty, no direct action button to add job to specific column.

## Minor Observations
- Notes saving indicator is text-only. A simple animated micro-spinner would clarify state changes.
- Delete buttons have no confirmation step, making accidental deletion easy.

## Questions to Consider
- What if cards used subtle tags and borders instead of colored status stripes?
- What would a confident layout look like without uppercase tracked headings?
